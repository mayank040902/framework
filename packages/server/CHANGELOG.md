# Changelog

All notable changes to this project are documented in this file.

## 1.0.0 - 2026-09-26

### Added

- Fastify bootstrap with `createServer` and `startServer`
- Optional plugins for logger, database, kafka, redis, realtime, and errors
- Health routes and graceful shutdown
- TypeScript declarations, tests, examples, and npm package metadata

### Changed

- Published independently as `@bootstrap-framework/server`
- Sibling packages are optional peers, not workspace runtime dependencies
