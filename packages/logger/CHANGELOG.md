# Changelog

All notable changes to this project are documented in this file.

## 1.0.0 - 2026-09-26

### Added

- Standalone Pino logger with development, production, and test modes
- HTTP logger via `pino-http`
- Request, response, and error serializers
- Optional pretty, file, and stream transports
- TypeScript declarations, tests, examples, and npm package metadata

### Changed

- Published independently as `@bootstrap-framework/logger`
